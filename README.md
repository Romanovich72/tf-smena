# Ночная смена — тренажёр входящих звонков ТФ

Статический веб-тренажёр на HTML, CSS и JavaScript. Для локального просмотра откройте `index.html` в современном браузере. Для публикации в GitHub Pages выберите ветку репозитория и папку `/ (root)` в настройках Pages.

## Режимы

- **Рабочая смена** — три звонка подряд. Для каждой новой смены случайно выбираются три разных клиента из четырёх: Аналитик, Торопыга, Требовательная клиентка и Тревожный новичок.
- **Свободная тренировка** — отдельный клиентский сценарий. Попытка помечается «Тренировка» и не смешивается с официальной статистикой смен.
- В профиле доступны сводка «Всё время» и раздельные виды «Смены» / «Тренировки».

## Оценка

Чек-лист Д2 из `metodichka.txt.txt`: десять критериев, каждый даёт ровно 0 или 2 балла. Успешная запись требует не менее 16/20 и двух баллов по C4, C9 и C10. Доверие начинается с 50/100; звонок завершается при падении до 15 или ниже либо после двух грубых ошибок подряд. Баллы не сгорают.

Попытки хранятся в `localStorage` браузера и остаются на этом устройстве. Очистка данных сайта удаляет историю.

## Добавление сценариев

Каталог клиентов, стартовые контексты, узлы звонка, ответы и эталонные речевые модули находятся в `scenarios.js`. У ответа задаются стабильное событие чек-листа, изменение доверия и признак грубой ошибки. Случайный порядок относится только к показу кнопок и не меняет их оценку.

## Файлы

- `index.html`, `styles.css`, `app.js` — интерфейс и режимы.
- `scenarios.js` — контент.
- `engine.js` — ветвления, доверие и баллы.
- `report.js` — история и профиль.
- `assets/` — шесть иллюстраций комикса.
